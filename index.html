MÓDULO 01 / HTML

HTML: la estructura de la página

HTML significa HyperText Markup Language. Define la estructura del contenido: títulos, párrafos, imágenes, enlaces y listas.

<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola, web!</h1>
    <p>Estoy aprendiendo HTML.</p>
    <a href="https://example.com">Un enlace</a>
  </body>
</html>

Etiquetas comunes

<h1> título · <p> párrafo · <a> enlace · <img> imagen · <ul> lista.

Atributos

Aportan información adicional. href indica el destino de un enlace y src la ruta de una imagen.

HTML estructura el contenido; CSS define el aspecto y JavaScript añade comportamiento interactivo.
MÓDULO 02 / CSS

CSS: dale estilo a tu web

CSS significa Cascading Style Sheets. Controla colores, tipografías, espacios, bordes y distribución. Una regla combina un selector con declaraciones.

h1 {
  color: #f7df1e;
  font-size: 2rem;
}

.tarjeta {
  background: #18233b;
  padding: 20px;
  border-radius: 12px;
}

Selectores

h1 selecciona los títulos h1. .tarjeta selecciona los elementos con esa clase.

Propiedades

color, background, font-size, margin y padding son propiedades habituales.

Prueba el estilo

Cambia el color y el tamaño para ver cómo CSS modifica el aspecto del elemento.

¡Hola, CSS!

Este contenido HTML tiene estilo CSS.

Lo habitual es guardar CSS en styles.css y conectarlo dentro de <head> con <link rel="stylesheet" href="styles.css">.

JavaScript

01 / FUNDAMENTOS

Variables: guardar información

Una variable es un nombre que usamos para guardar un valor. En JavaScript moderno, utiliza const si no vas a reasignar el valor y let si necesitas cambiarlo.

const nombre = "Alex";
let puntos = 10;
puntos = puntos + 5;

console.log(nombre); // Alex
console.log(puntos); // 15
Consejo: evita var cuando estés empezando; let y const tienen un comportamiento de ámbito más predecible.
02 / FUNDAMENTOS

Tipos de datos

Los valores pueden ser de diferentes tipos. Estos son algunos de los más habituales:

String

"Hola mundo"

Texto entre comillas.

Number

42 · 3.14

Números enteros o decimales.

Boolean

true · false

Verdadero o falso.

Array

["rojo", "azul"]

Una lista ordenada de valores.

const edad = 20;
const esEstudiante = true;
const colores = ["rojo", "azul"];

console.log(typeof edad); // "number"
03 / TOMAR DECISIONES

Condiciones: if y else

Las condiciones permiten ejecutar un bloque de código u otro según se cumpla una expresión.

const edad = 18;

if (edad >= 18) {
  console.log("Puedes entrar");
} else {
  console.log("Aún no puedes entrar");
}

Operadores útiles: === igual estricto, !== distinto, > mayor, <= menor o igual, && y, || o.

04 / REPETIR TAREAS

Bucles: for

Un bucle repite instrucciones. Este ejemplo cuenta del 1 al 5:

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

El bucle tiene tres partes: inicialización (let i = 1), condición (i <= 5) y actualización (i++).

05 / REUTILIZAR CÓDIGO

Funciones

Una función agrupa instrucciones para poder ejecutarlas cuando las necesites. Puede recibir parámetros y devolver un resultado.

function saludar(nombre) {
  return `¡Hola, ${nombre}!`;
}

console.log(saludar("Lucía")); // ¡Hola, Lucía!
La palabra return devuelve un valor. No es lo mismo que console.log(), que muestra un mensaje en la consola.
06 / COLECCIONES

Arrays: listas de valores

Los arrays guardan varios valores en una sola variable. Sus posiciones empiezan en cero.

const frutas = ["manzana", "pera", "kiwi"];

console.log(frutas[0]); // manzana
frutas.push("mango");   // añade un elemento
console.log(frutas.length); // 4

Prueba también métodos como includes(), map() y filter() cuando tengas más práctica.
